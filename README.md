# 🍔 Dippin Dot's Restaurant — Offline HTML Code & Run Guide

**Baghair kisi deployment (Vercel / Hosting) ke direct chalane ka tareeqa:**

Aapko website chalane ke liye kisi server ya Vercel deploy karne ki **bilkul zaroorat nahi hai**. Humne poori website ek **Single Standalone HTML File** (`dippin-dots.html`) mein tayyar kar di hai.

---

## ⚡ Option 1: 1-Click Mein Chalane Ka Tareeqa (PC / Laptop)

1. Apne computer par **Notepad** (ya VS Code) open karein.
2. Niche diya gaya HTML code copy karke Notepad mein paste karein.
3. File ko save karte waqt name rakhein:  
   `index.html` (aur Save as type mein **All Files (*.*)** select karein).
4. Ab is `index.html` file par **Double-Click** karein!
5. 🎉 Website foran aapke Google Chrome ya Microsoft Edge browser mein live chal jayegi!

---

## 📥 Option 2: GitHub Se Direct Download Karna

Aapki GitHub repository mein bhi ye file push ho chuki hai:
🔗 **Repository URL:**  
[https://github.com/Aaliyan112/dippin-dot-s-restaurant](https://github.com/Aaliyan112/dippin-dot-s-restaurant)

1. Upar wale link par jayein.
2. Wahan green **`Code`** button par click karein aur **`Download ZIP`** par click karein.
3. ZIP file extract karein.
4. Folder mein mojood **`dippin-dots.html`** par double-click karein — website complete images, cart, aur WhatsApp ordering ke sath khul jayegi!

---

## 🚀 Agar Kabhi Free Live Link Chahiye Ho (Client Ko Link Bhejne Ke Liye)

Vercel mein complicated steps ke bajaye:
- GitHub repository ke **Settings** > **Pages** mein jayein.
- Branch mein **main** select karke **Save** karein.
- 1 minute mein aapko free live link mil jayega jese:  
  `https://aaliyan112.github.io/dippin-dot-s-restaurant/dippin-dots.html`
